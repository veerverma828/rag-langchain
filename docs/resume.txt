LocalRAG - Built a fully local retrieval-augmented generation pipeline in Python using Ollama for both embeddings (nomic-embed-text) and text generation (llama3.2:3b). The system reads documents from a folder (supporting .txt and .pdf files), splits them into overlapping chunks, converts each chunk into a vector embedding, and retrieves the most relevant chunks using cosine similarity before generating a grounded answer to a user's question. Implemented source citation so answers reference the exact file they came from, and added error handling for unreadable files and oversized chunks during ingestion.
